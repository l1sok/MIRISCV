# Отчет по лабораторным ПрМиСнК

## Задание

В рамках 3 и 4 лабораторных работ по курсу "Процессорные микроархитектуры и системы на кристалле" были поставлены следующие задачи над процессорным ядром MIRISCV:

* Изучить ядро и добавить в него стадию “memory plus”, убирающую задержки при доступе в память.

* Добавить байпассы в ядро и оценить эффекты, которые байпассы оказывают на производительность и тайминги ядра.
